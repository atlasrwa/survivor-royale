# Assets

Game assets directory.

## Structure

- `sprites/` - Character sprites, enemy sprites, weapon effects
- `audio/` - Sound effects, music
- `fonts/` - Custom fonts for UI
- `ui/` - UI elements, buttons, panels

## Asset Guidelines

- Sprites: PNG format, transparent backgrounds
- Audio: OGG for web compatibility
- Keep file sizes optimized (use compression)
- Organize by category (heroes/, enemies/, weapons/, etc.)

## Placeholder Assets

For initial development, use:
- [Kenney Assets](https://kenney.nl/assets) (free, public domain)
- [OpenGameArt](https://opengameart.org/)
- Colored rectangles as placeholders
