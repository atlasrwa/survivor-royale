## 🚨 Critical Gaps — What's Missing for "State-of-the-Art"

### GAP 1: No Web3 Integration (The Crypto-Gamer Hook)

| Priority | P0 — The entire Web3 promise is unfulfilled |
|----------|------|
| **What's missing** | Wallet connection, on-chain leaderboard, $RIFT token integration, NFT cosmetics |
| **Why it matters** | The game is marketed as a crypto game. Zero blockchain touchpoints means zero crypto-native appeal. Players expect wallet-gated features, on-chain scores, and token rewards |
| **What to build** | RainbowKit wallet modal → connected state in UI → submit scores on-chain → read leaderboard from contract → display in-game |
| **Tech available** | wagmi ^2.9.0, @rainbow-me/rainbowkit ^2.0.0, viem ^2.10.0, ethers ^6.12.0 — all already in package.json |

### GAP 2: No Battle Pass / Season System

| Priority | P0 — The #1 retention mechanism in mobile gaming |
|----------|------|
| **What's missing** | Time-gated progression rewards (battle pass tiers), season themes, premium track |
| **Why it matters** | The meta-shop is "spend gold, get stat bonus." That's necessary but not sufficient. Battle passes create FOMO + daily engagement + "just one more game to hit next tier." Every successful mobile game has one |
| **What to build** | Season definition (start/end dates, tiers) → XP/score feeds into season progress → tier rewards (gold, cosmetics, skill points) → free + premium tracks → daily/weekly missions feed into it |
| **Crypto angle** | Premium track purchasable with $RIFT tokens. Season-exclusive NFT cosmetics at tier milestones |

### GAP 3: No Run Summary / Statistics Screen

| Priority | P1 — Social proof and viral loop |
|----------|------|
| **What's missing** | After game over, player sees stats but can't review the run in detail or share it |
| **Why it matters** | The GameOverScene just shows wave/score/kills. No breakdown of damage dealt, upgrades chosen, boss times, comparisons to personal best. No screenshot/shareable card for Twitter/Discord |
| **What to build** | Run summary screen with: DPS graph, upgrade timeline, damage breakdown by enemy type, "shareable card" (canvas-rendered screenshot) with stats + hero art |
| **Crypto angle** | Optional: mint your best run as an NFT achievement |
